Chapter 9 Homology and multiple sequence alignments

Homologous genes share a common ancestor. When we line up homologous sequences in a multiple sequence alignment (MSA), we can see which positions changed over evolution and which stayed the same, and that tells us what parts of a protein matter.

In this lab you will follow the workflow real researchers use:

get sequences → align them → build a tree → find where the protein changes (and where it doesn’t)

Our protein is MSH2, a DNA mismatch repair protein. In humans, damage to MSH2 causes Lynch syndrome, a hereditary cancer predisposition. By the end you will be able to answer: which parts of this protein are the most important, and how can we tell?

9.4 Part 3: Build a tree from the alignment

An alignment tells us which positions are homologous, so we can measure how different each pair of sequences is and build a tree of their relationships. We will use the neighbor-joining method, with bootstrapping to measure how much we can trust each branch.

pd   <- phyDat(as.matrix(aln), type = "AA")
dm   <- dist.ml(pd, model = "WAG")     # pairwise distances between sequences
tree <- midpoint(NJ(dm))               # build the tree and root it at its midpoint

# Bootstrap: repeat the tree-building 100 times on resampled columns
bs <- bootstrap.phyDat(pd, function(x) NJ(dist.ml(x, model = "WAG")), bs = 100)

plotBS(tree, bs, p = 50, type = "phylogram", cex = 0.8)

The numbers on the branches are bootstrap values (out of 100). Higher means more support.

9.5 Part 4: Where are the most (and fewest) changes?

Now for the question that matters biologically: which parts of MSH2 stay the same across species (probably important) and which change a lot (probably tolerate change)?

9.5.1 Step 1: Measure conservation at every position

For each column in the alignment, we calculate the fraction of sequences that share the most common amino acid. 1 means everyone is identical, and lower numbers mean more variation.

m <- as.matrix(aln)

conservation <- apply(m, 2, function(x) {
  x <- x[x != "-"]                     # ignore gaps
  if (length(x) == 0) return(NA)
  max(table(x)) / length(x)
})

9.5.2 Step 2: Use human residue numbers

Alignment columns do not match the real protein positions because of gaps. We want everything numbered by the human MSH2 protein, so we count residues along the human row:

human <- m[grep("MSH2_HUMAN", rownames(m)), ]

cons <- tibble(
  column       = seq_along(human),
  residue      = ifelse(human == "-", NA, cumsum(human != "-")),
  conservation = conservation
) |>
  filter(!is.na(residue))

# A smoothed line (average of 15 neighboring residues) is easier to read
cons$smooth <- as.numeric(stats::filter(cons$conservation, rep(1/15, 15), sides = 2))

head(cons)

9.6 Part 5: Real-world connection: mutations that cause disease

If a position is the same across all species, a change there is more likely to harm the protein. Researchers use this idea to judge whether a human mutation might cause disease.

  1. Go to ClinVar and search MSH2[gene]. Filter for missense variants (single amino acid changes).
  2. Choose three pathogenic variants and three benign variants. Note the position in each (for example, p.Gly67Arg is position 67).
  3. Add them to the code below and plot them on your conservation figure:
