Chapter 12 Part 2: Is Everything Turning Into a Crab?

12.1 Carcinization

In 1916 the zoologist L.A. Borradaile noticed that unrelated crustaceans kept evolving into crab-shaped animals, and called it “one of the many attempts of Nature to evolve a crab.” The process now has a name: carcinization.

Here’s the twist: not every crab is a crab.

  • True crabs (Brachyura): blue crabs, edible crabs, spider crabs, ghost crabs…
  • False crabs (Anomura): the relatives of hermit crabs and squat lobsters. Some of them (king crabs, porcelain crabs) look exactly like crabs, but evolved that shape on their own.

Evolution can also go the other way: some crab-shaped lineages lost the crab body. That’s called decarcinization.

In this lab, an animal counts as crab-like if it has both of these:

  1. a wide, flat, hard upper shell (the carapace), and
  2. the abdomen (the “tail”) folded tightly underneath the body.

A hermit crab has a soft abdomen curled into a snail shell, so it’s not crab-like. A lobster has a long tail sticking out the back, so it’s not crab-like either.

Ancestral state reconstruction (ASR) takes a tree and the traits we can see in living species, and estimates what the traits were in ancestors we can’t see. That lets us count how many times a trait was gained or lost.

12.2 The data

We’ll use 36 decapod crustaceans. The tree is a simplified version of published phylogenies of crabs and their relatives (Bracken-Grissom et al. 2013, BMC Evolutionary Biology; Wolfe et al. 2021, BioEssays). Some relationships are still debated, so where the experts don’t agree, the tree has a polytomy (a node with more than two branches).

  1. Load the tree and the trait data:
decapods <- read.tree(text = "((Homarus_americanus,Procambarus_clarkii),((Dromia_personata,(Homola_barbata,(Ranina_ranina,((Callinectes_sapidus,Cancer_pagurus,Macrocheira_kaempferi,Carcinus_maenas,Menippe_mercenaria),(Ocypode_quadrata,Leptuca_pugilator,Grapsus_grapsus))))),((Emerita_analoga,Emerita_talpoida,Hippa_pacifica),((Aegla_platensis,(Lomis_hirta,Kiwa_hirsuta,Uroptychus_nitidus)),(Munida_gregaria,Galathea_strigosa,Pleuroncodes_planipes,(Petrolisthes_cinctipes,Petrolisthes_armatus,Porcellana_platycheles,Euceramus_praelongus)),((Dardanus_venosus,Clibanarius_vittatus,(Coenobita_clypeatus,Birgus_latro)),(Pagurus_bernhardus,Pagurus_longicarpus,(Paralithodes_camtschaticus,Paralithodes_platypus,Lithodes_maja)))))));")

  1. Our ASR methods need every node to split in two, so we’ll randomly resolve the polytomies with multi2di(). We don’t have real branch lengths for this tree (it was assembled from several studies), so we’ll set every branch to length 1.
set.seed(1)
tr <- multi2di(decapods)
tr <- compute.brlen(tr, 1)

body <- setNames(ifelse(crab_like[tr$tip.label] == 1, "crab", "not_crab"), tr$tip.label)
cols <- c(crab = "orangered", not_crab = "steelblue")

plot(tr, cex = 0.7, label.offset = 0.1, tip.color = cols[body])
legend("topleft", legend = c("crab-like", "not crab-like"), fill = cols, bty = "n")

  • Make a prediction before you run anything. Just by looking at the tree and the colors, how many times do you think the crab body evolved? Was the common ancestor of all crabs (true and false) crab-like?
  • King crabs look like true crabs. Where are they on the tree, and who are their closest relatives? Does that surprise you?

12.3 Method 1: Parsimony

  1. Parsimony asks: what is the smallest number of changes (gains or losses of the crab body) needed to explain the colors on the tips?
body_data <- phyDat(as.matrix(body), type = "USER", levels = c("crab", "not_crab"))
parsimony(tr, body_data)

Question 3

  • What is the minimum number of changes? Draw (or describe) one scenario on the tree that uses exactly that number of changes. How many are gains and how many are losses in your scenario?

12.4 Method 2: Maximum likelihood

  1. Parsimony gives one answer and no measure of uncertainty. Maximum likelihood fits a model where the trait can switch between states at some rate, and gives the probability that each ancestor was crab-like:
fit <- ace(body, tr, type = "discrete", model = "ER")

plot(tr, cex = 0.7, label.offset = 0.1, tip.color = cols[body])
nodelabels(pie = fit$lik.anc, piecol = cols, cex = 0.5)
legend("topleft", legend = c("crab-like", "not crab-like"), fill = cols, bty = "n")

Each pie chart is an ancestor. The more orange the pie, the more likely that ancestor was crab-like.

  1. Let’s get the exact probabilities for some important ancestors. getMRCA() finds the most recent common ancestor of two species:
anc <- fit$lik.anc
rownames(anc) <- (Ntip(tr) + 1):(Ntip(tr) + tr$Nnode)

prob_crab <- function(sp1, sp2) {
  round(anc[as.character(getMRCA(tr, c(sp1, sp2))), "crab"], 2)
}

prob_crab("Dromia_personata", "Lithodes_maja")        # ancestor of ALL crabs (true + false)
prob_crab("Emerita_analoga", "Lithodes_maja")         # ancestor of false crabs (Anomura)
prob_crab("Dromia_personata", "Ocypode_quadrata")     # ancestor of true crabs (Brachyura)
prob_crab("Pagurus_bernhardus", "Lithodes_maja")      # ancestor of hermit crabs + king crabs

Questions 4 - 5

  • Was the ancestor of the false crabs (Anomura) crab-like? Was the ancestor of the true crabs (Brachyura)? How confident is each answer? Based on this, how many times did the crab body evolve within the true crabs?
  • King crabs are crab-like. Their ancestor with hermit crabs was not. So what was the ancestor of king crabs carrying around on its back?

12.5 Method 3: Counting gains and losses

  1. Stochastic character mapping simulates 100 possible histories of the trait on the tree, in proportion to how likely each one is. Then we can count how many gains and losses happen in an average history:
maps <- make.simmap(tr, body, model = "ER", nsim = 100, message = FALSE)
history <- summary(maps)

colMeans(history$count)   # N = total changes; then crab -> not_crab (losses), not_crab -> crab (gains)
plot(history, colors = cols, fsize = 0.6)

Question 6

  • On average, how many times was the crab body gained and how many times was it lost? Why is the total higher than the parsimony number from Question 3?
