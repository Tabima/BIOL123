Introduction to Bioinformatics: Excercise Guidebook

Chapter 10 Phylogenetics: Playing God and Catching a Fungus

In this lab you’ll do two things that real phylogeneticists do all the time, and that most intro classes skip:

  1. Play God. You’ll create your own group of imaginary creatures, evolve their DNA in the computer, and hide the true family tree in a sealed envelope. Then you’ll use IQ-tree to try to reconstruct it and see how close you get. This is the only time you’ll ever know the right answer for a phylogeny, so it’s the only time you can actually check whether your methods work.
  2. Catch a fungus. A zombie-ant-style fungus (Ophiocordyceps) is infecting students in two dorms. You have DNA from the patients and from three suspects. You’ll use a tree to figure out where the outbreak came from, who infected whom, and whether the mycology lab is to blame.

This second part is called genomic epidemiology, and it’s the same approach public health labs used to track SARS-CoV-2, mpox and Candida auris outbreaks.

10.1 Introduction to IQ-tree

We will use IQ-tree, one of the most widely used programs for building phylogenetic trees. IQ-tree:

  • Uses maximum likelihood: it searches for the tree that makes your data most probable under a model of evolution.
  • Runs ModelFinder first to pick the best model of substitution for your data (remember AIC/BIC from lecture).
  • Runs ultrafast bootstraps to tell you how much to trust each branch.

The basic command is:

iqtree2 -s your_alignment.fasta -B 1000

Tip: IQ-tree won’t overwrite an earlier run with the same name. If you need to rerun something, add -redo to the command.

We’ll run IQ-tree from the Terminal tab in RStudio on pippin, and do everything else in R.

And in , load the libraries:

library(ape)
library(phangorn)

10.2 Part 1: Playing God

10.2.1 Create your creatures

  1. Invent 12 creatures. Give them names, the weirder the better ("Glorbo", "Sir_Wigglesworth", "Toast_Moth"…). Use no spaces in the names; use _ instead.

  2. Use your student ID number (or any number you like) as your random seed. That makes your world yours: nobody else in the class will have the same tree.

set.seed(12345)   # <- change this to your own number

my_creatures <- c("Glorbo", "Sir_Wigglesworth", "Toast_Moth", "Captain_Spore",
                  "Blorp", "Mildred", "Snorkelbeast", "Fungal_Fiona",
                  "Gerald", "Velvet_Worm_Steve", "Zoomba", "The_Professor")

# Make a random family tree for your creatures
true_tree <- rtree(12, tip.label = my_creatures)
true_tree$edge.length <- true_tree$edge.length * 0.2   # keep branches realistic

# SEAL THE ENVELOPE. Do not look at this tree until step 8!
write.tree(true_tree, "SEALED_true_tree.nwk")

10.2.2 Evolve their DNA

  1. Now let evolution happen. simSeq() starts with one ancestral sequence at the root and lets mutations accumulate along every branch of your tree, just like real evolution, until it reaches your 12 living creatures.

We’ll make three datasets of different sizes: a tiny 20 bp gene, a short 100 bp gene, and a decent 1,000 bp gene.

for (len in c(20, 100, 1000)) {
  dna <- simSeq(true_tree, l = len, type = "DNA")
  write.phyDat(dna, paste0("creatures_", len, "bp.fasta"), format = "fasta")
}

These sequences are already aligned (our simulation has no insertions or deletions), so we can go straight to tree building.

10.2.3 Reconstruct the tree

  1. In the Terminal, run IQ-tree on all three files:
for len in 20 100 1000; do
  iqtree2 -s creatures_${len}bp.fasta -B 1000 --prefix creatures_${len}bp
done

Questions 1 - 3

  • Look at the .iqtree file for the 1,000 bp run. What is the best-fit model according to BIC? The simulation used the simplest possible model of DNA evolution (Jukes-Cantor, JC). Did IQ-tree figure that out for all three lengths? If not, why might it pick a more complex model?
  • Use code (e.g. grep) to pull the log-likelihood of the tree out of each .iqtree file. Paste your code and the three values. Why can’t you compare these three numbers to decide which tree is “best”?
  • How many parsimony-informative sites did IQ-tree find in each alignment (it’s in the .iqtree file)? Why does this number matter more than the raw length?

10.2.4 Look at your trees

  1. Plot your three reconstructed trees with their bootstrap support:
par(mfrow = c(1, 3))
for (len in c(20, 100, 1000)) {
  tr <- read.tree(paste0("creatures_", len, "bp.treefile"))
  tr <- midpoint(tr)    # ML trees are unrooted; root them at the midpoint
  plot(tr, main = paste(len, "bp"), cex = 0.8)
  nodelabels(tr$node.label, frame = "none", adj = c(1.2, -0.4), cex = 0.7, col = "red")
}

Remember: bootstrap values above 75% are generally considered well supported, and above 95% strongly supported.

Question 4

  • Before opening the envelope: which of your three trees do you trust the most, and why? Which specific relationships would you bet money on?

10.2.5 Open the envelope

  1. Now compare each reconstruction to the truth. The Robinson-Foulds (RF) distance counts how many branches (splits) are in one tree but not the other. RF = 0 means you got the tree exactly right. For 12 creatures, the worst possible score is 18.
true_tree <- read.tree("SEALED_true_tree.nwk")

for (len in c(20, 100, 1000)) {
  tr <- read.tree(paste0("creatures_", len, "bp.treefile"))
  cat(len, "bp -> RF distance:", RF.dist(true_tree, tr, rooted = FALSE), "\n")
}
  1. Put the truth and your best guess side by side. The lines connect the same creature in both trees:
est <- read.tree("creatures_1000bp.treefile")
est <- root(est, outgroup = true_tree$tip.label[1], resolve.root = TRUE)
true_rooted <- root(true_tree, outgroup = true_tree$tip.label[1], resolve.root = TRUE)
cophyloplot(true_rooted, est,
            assoc = cbind(true_rooted$tip.label, true_rooted$tip.label),
            length.line = 4, space = 60, gap = 3)
title("Truth (left) vs. IQ-tree 1000 bp (right)")

10.3 Part 2: The Campus Outbreak

10.3.1 The case

URGENT – Office of the Dean of Students

Over the past three weeks, 16 students from Dorm A and Dorm B have come to Health Services with fatigue, an unusual craving to climb to high places, and a fuzzy white growth behind the ears. Culture results show an Ophiocordyceps fungus.

We have sequenced the same 1.5 kb marker gene from every patient, and from three possible sources:

  • Forest_*: wild Ophiocordyceps collected in the woods behind campus.
  • LabStock_*: strains from the mycology lab’s freezer. (The mycology lab says it’s definitely not them.)
  • Smoothie_*: fungus cultured from two lots of “Brain Boost” mushroom powder sold at the campus smoothie bar.

A Cordyceps militaris sequence is included as an outgroup.

We need to know: Where did this come from? Is it spreading between dorms? Who is to blame?

  1. Download outbreak_unaligned.fasta and outbreak_metadata.csv from (here)[https://github.com/Tabima/BIOL123/raw/refs/heads/main/Lab6/outbreak_data.zip] and put them in your folder.

10.3.2 Align the sequences

  1. Unlike your creatures, these sequences have insertions and deletions, so they need aligning first. Align them with MAFFT:
system('mafft --auto outbreak_unaligned.fasta > outbreak_aligned.fasta')
  1. Build the tree:
system('iqtree2 -s outbreak_aligned.fasta -B 1000 --prefix outbreak')
  1. Plot it in R, coloring the samples by where they came from:
meta <- read.csv("outbreak_metadata.csv")
tr   <- read.tree("outbreak.treefile")
tr   <- root(tr, outgroup = "Outgroup_Cordyceps", resolve.root = TRUE)

colors <- c("Forest" = "darkgreen", "LabStock" = "purple", "Smoothie" = "orange",
            "Infected student" = "red", "Outgroup (C. militaris)" = "grey40")
tip_source <- meta$source[match(tr$tip.label, meta$sample)]

par(mfrow = c(1, 1))
plot(tr, tip.color = colors[tip_source], cex = 0.8)
nodelabels(tr$node.label, frame = "none", adj = c(1.2, -0.4), cex = 0.6)
add.scale.bar()
legend("right", legend = names(colors), text.col = colors, bty = "n")

10.3.3 Fix it

  1. Somebody in the sequencing facility loaded one sample backwards: it’s the reverse complement of the real sequence. MAFFT can detect and flip backwards sequences for you:
system('mafft --adjustdirectionaccurately --auto outbreak_unaligned.fasta > outbreak_fixed.fasta')
system('iqtree2 -s outbreak_fixed.fasta -B 1000 --prefix outbreak_fixed')

MAFFT adds _R_ to the start of the name of any sequence it flipped. Run grep "_R_" outbreak_fixed.fasta to check which one it was. Then clean up the name in R before plotting, and replot your tree using outbreak_fixed.treefile:

tr <- read.tree("outbreak_fixed.treefile")
tr <- midpoint(tr)
tr$tip.label <- sub("^_R_", "", tr$tip.label)

colors <- c("Forest" = "darkgreen", "LabStock" = "purple", "Smoothie" = "orange",
            "Infected student" = "red", "Outgroup (C. militaris)" = "grey40")
tip_source <- meta$source[match(tr$tip.label, meta$sample)]

par(mfrow = c(1, 1))
plot(tr, tip.color = colors[tip_source], cex = 0.8)
nodelabels(tr$node.label, frame = "none", adj = c(1.2, -0.4), cex = 0.6)
add.scale.bar()
legend("right", legend = names(colors), text.col = colors, bty = "n")

10.3.4 Solve the case

  1. Now color the infected students by dorm instead of by source:
tip_dorm <- meta$dorm[match(tr$tip.label, meta$sample)]
dorm_colors <- ifelse(is.na(tip_dorm), "grey60",
                      ifelse(tip_dorm == "Dorm_A", "blue", "red"))
plot(tr, tip.color = dorm_colors, cex = 0.8)
nodelabels(tr$node.label, frame = "none", adj = c(1.2, -0.4), cex = 0.6)
legend("right", legend = c("Dorm A", "Dorm B", "Not a patient"),
       text.col = c("blue", "red", "grey60"), bty = "n")
  1. Use code to check your hypotheses. is.monophyletic() tells you whether a group of samples forms a single clade with nothing else mixed in:
patients <- grep("Patient", tr$tip.label, value = TRUE)
is.monophyletic(tr, patients)
is.monophyletic(tr, c(patients, "Smoothie_LotA", "Smoothie_LotB"))
is.monophyletic(tr, c(patients, "LabStock_1", "LabStock_2", "LabStock_3"))
