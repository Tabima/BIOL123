\hypertarget{rmark}{%
\chapter{Introduction to electronic notebooks in R Markdown}\label{rmark}}

The electronic lab notebooks we will use will in class will be created as \texttt{R\ Markdown\ documents}.

Markdown is a simple formatting syntax for authoring HTML, PDF, and MS Word documents. For more details on using R Markdown see \url{http://rmarkdown.rstudio.com}.

When you click the \textbf{Knit} button a document will be generated that includes both content as well as the output of any embedded R code chunks within the document.

\hypertarget{markdown-formats}{%
\section{Markdown formats}\label{markdown-formats}}

As mentioned above, Markdown is a simple formatting syntax for authoring HTML, PDF, and MS Word documents.

We will use R Markdown as it will allow us to create documents that we can modify in different computers (as long as we have R and R Studio).

We will call these documents \emph{Electronic Lab Notebooks (ELS)}. These ELS' will be used to write down what you have done in class, save the results and the commands and also will tell us where the files you are using will be at.

But, before we go into the super complex part of it, lets learn the basics of R markdown.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{basics-of-markdown}{%
\section{Basics of Markdown}\label{basics-of-markdown}}

So, the idea to use the R markdown file as a E-notebook we need to understand what the syntax is.

\begin{quote}
Syntax: a set of rules for or an analysis of the syntax of a language
\end{quote}

\hypertarget{basic-syntax}{%
\subsection{Basic syntax}\label{basic-syntax}}

In the case of markdown, all the text that is not formatted in any way will be displayed in the most basic font.

So you'll see that all of these sentences are in simple format.

In addition, if you surround words with certain elements, it can become a word in \textbf{bold} or in \emph{italics}.

In this case, when I add a \texttt{**} before and after the word I want to highlight, the word becomes a bold word. When I add a \texttt{**} before and after the word I want to highlight, the word becomes a word in italics.

If you want to add a header, or a subtitle, start a sentence with \texttt{\#}. One \texttt{\#} means main header, two will be a subtitle, and so on.

\hypertarget{lines-of-code}{%
\subsection{Lines of code}\label{lines-of-code}}

Markdown allows you to create unformatted lines, or lines of code. In these lines you can add the code you are using for certain steps, or to illustrate examples.

To create a code in-line, just add a `\texttt{(backtick)} between the line of code

\hypertarget{example-of-inline-code}{%
\subsubsection{Example of inline code:}\label{example-of-inline-code}}

Similarity searches were done using \texttt{blastn} with default parameters and an expected E-value of 10-5.

\hypertarget{example-of-code-blocks}{%
\subsubsection{Example of code blocks:}\label{example-of-code-blocks}}

To create a code block, start a region with three `\texttt{(backticks)}. Add the code in the line after the backticks and then close with three additional backticks.

\begin{verbatim}
This is a code-block
blastp -query q
\end{verbatim}

\hypertarget{lists}{%
\subsection{Lists}\label{lists}}

You can create unordered or ordered lists in Markdown.
To create \textbf{unordered} lists in markdown, start each element of the list with a \texttt{-} sign:

\textbf{Code:}

\begin{verbatim}
- Bananas
- Pijamas
- Bandanas
\end{verbatim}

\textbf{Result:}

\begin{itemize}
\tightlist
\item
  Bananas
\item
  Pijamas
\item
  Bandanas
\end{itemize}

To create ordered lists, add a number with a period before each element. The numbers don't have to be consecutive, which will allow Markdown to modify the list no problem \emph{(Check the raw code before you run the Knitr command)}:

\textbf{Code:}

\begin{verbatim}
1. Wake up
1. Make the bed
1. Lie down again
\end{verbatim}

\textbf{Result:}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Wake up
\item
  Make the bed
\item
  Lie down again
\end{enumerate}

You can also make nested lists! Nested lists can are done by creating list using \textbf{4} spaces:

\textbf{Code:}

\begin{verbatim}
1. This week:
    - Homework
    - Breakfast
    - Cats litter
2. This weekend
    - Nothing
\end{verbatim}

\textbf{Result:}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  This week:

  \begin{itemize}
  \tightlist
  \item
    Homework
  \item
    Breakfast
  \item
    Cats litter
  \end{itemize}
\item
  This weekend

  \begin{itemize}
  \tightlist
  \item
    Nothing
  \end{itemize}
\end{enumerate}

\hypertarget{horizontal-rules}{%
\subsection{Horizontal rules}\label{horizontal-rules}}

If you want to separate sections by a horizontal rule, use three \texttt{*} in a row in an empty line:

\begin{verbatim}
***
\end{verbatim}

\hypertarget{links-figures-and-tables}{%
\subsection{Links, figures and tables}\label{links-figures-and-tables}}

Finally, we can add links, figures and tables in the Markdown document

\hypertarget{hyperlinks}{%
\subsubsection{Hyperlinks}\label{hyperlinks}}

To add a link in markdown, just use the \texttt{{[}link\ name{]}(link\ address)} syntax, where you add the link of interest in the parenthesis and a generic name for the link between the square brackets.

For example, if I want to link NCBI, then the code should be \texttt{{[}NCBI{]}(ncbi.nlm.nih.gov/)}, and it will look like this: \href{ncbi.nlm.nih.gov/}{NCBI}

\hypertarget{figures}{%
\subsubsection{Figures}\label{figures}}

To add a figure from the internet you use a similar syntax than what we used in the \emph{links} section, but with a exclamation mark at the beginning of the syntax: \texttt{!{[}Clark\ Logo{]}(https://www.clarku.edu/wp-content/themes/clarku/assets/img/main-logo.svg)} results in

\begin{figure}
\centering
\includegraphics{https://www.clarku.edu/wp-content/themes/clarku/assets/img/main-logo.svg}
\caption{Clark Logo}
\end{figure}

You can also add images that are not online. For this, you can just upload the image of interest into the folder where your Markdown file is and link it locally as such: \texttt{!{[}Local\ Image\ of\ my\ cat{]}(cat\_img.JPG)} using the \texttt{Upload} button in the File Panel Viewer in your lower right.

\hypertarget{tables}{%
\subsection{Tables}\label{tables}}

Finally, lets learn how to add tables.

Tables in markdown can be annoying, but gladly there are online elements that will help us with tables.

However, lets start basic. A table can be created by having list of words and separating them with hyphens \texttt{-} (for the first row), and then separating each column with a pipe \texttt{\textbar{}}:

\begin{longtable}[]{@{}ll@{}}

Header One & Header Two \\
\midrule()
\endhead
Cell {[}1,1{]} & Cell {[}1,2{]} \\
Cell {[}2,1{]} & Cell {[}2,2{]} \\

\end{longtable}

The UNIX command line is a program that will interpret commands, in the form of text instructions, for the computer to be executed.

This means that you can tell the computer to \texttt{list\ files} or \texttt{print\ text\ in\ the\ screen} or \texttt{do\ a\ mathematical\ operation} using a set of commands and the computer will exacute them and provide you with an answer.

However, before we start using the command line I decided to make a list of the most commonly used commands in UNIX for your future reference.

\hypertarget{what-is-a-pipeline}{%
\subsection{What is a pipeline?}\label{what-is-a-pipeline}}

Pipelines are \textbf{sequential lines of code that can be used to use multiple commands at once}.

For example, if you want to count all the \texttt{U} in a DNA sequence that you have transformed into DNA, you can actually do this in one simple line of code.

Think about this as a logical set of steps (or, a \emph{pseudocode}):

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Read the DNA file
\item
  Replace the \texttt{T} for \texttt{U}
\item
  Extract the matches to \texttt{U}
\item
  Count those matches
\end{enumerate}

Using the command line the intructions would be like:

\begin{verbatim}
cat file.txt
sed 's/T/U/g' file.txt > file_rna.txt
grep -o U file_rna.txt > U_ocurrences.txt
wc -l U_ocurrences.txt
\end{verbatim}

This code works, but its quite useless as it forces us to create two independent files: \texttt{file\_rna.txt} and \texttt{U\_ocurrences.txt}.

Imagine that the output of these files were large and you had no space left in your hard drive! You would have to run everything again from the beginning!

One of the options is to use pipelines, using the \textbf{pipe (\texttt{\textbar{}}) modifier}. This modifier works as an \texttt{an\ then}.

So for example, a command that is like this: \texttt{ls\ -lrt\ \textbar{}\ grep\ seq\ \textbar{}\ wc\ -l} can be read as:

Make a list of all the files \textbf{and then} extract all the matches to \texttt{seq} \textbf{and then} count the number of occurences.

So, we can totally use this with out data.

\hypertarget{variables}{%
\paragraph{Variables}\label{variables}}

Variables can be defined as \textbf{a place to temporarly store a piece of information}.

For example, you wallet is a variable that is full of your money.

So, if you have \$10 in your wallet, then your variable is:

\begin{Shaded}
\begin{Highlighting}[]
\VariableTok{wallet}\OperatorTok{=}\NormalTok{10}
\end{Highlighting}
\end{Shaded}

So, that is how you define a variable in \texttt{bash}. To see what the value of that variable is, you use the \texttt{echo} command

\hypertarget{the-echo-command}{%
\paragraph{\texorpdfstring{The \texttt{echo} command}{The echo command}}\label{the-echo-command}}

The \texttt{echo} command will print to your screen whatever you tell it to print.

For example, if you tell the command to \texttt{echo\ \textquotesingle{}hello\textquotesingle{}}, this will happen:

\begin{Shaded}
\begin{Highlighting}[]
\BuiltInTok{echo} \StringTok{\textquotesingle{}hello\textquotesingle{}}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
## hello
\end{verbatim}

Meaning that you can tell it to say whatever you want to say. If you want to add spaces or other weird characters, make sure you surrond the statement with single quotes

\begin{Shaded}
\begin{Highlighting}[]
\BuiltInTok{echo} \StringTok{\textquotesingle{}This is the best course ever\textquotesingle{}}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
## This is the best course ever
\end{verbatim}

\hypertarget{mixing-variables-and-echo}{%
\paragraph{\texorpdfstring{Mixing variables and \texttt{echo}}{Mixing variables and echo}}\label{mixing-variables-and-echo}}

So, we want to mix these two because then you can store a variable and print it in the screen, for example:

\begin{Shaded}
\begin{Highlighting}[]
\VariableTok{statement}\OperatorTok{=}\StringTok{\textquotesingle{}This is the best course ever\textquotesingle{}}
\BuiltInTok{echo} \VariableTok{$statement}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
## This is the best course ever
\end{verbatim}

Look at this! You can simplify the instructions and print variables!

Now, did you notice that the variable \texttt{statement} had a \texttt{\$} in front? That is how you tell \texttt{bash} that you are using a variable!

If you don't add it this is what happens:

\begin{Shaded}
\begin{Highlighting}[]
\BuiltInTok{echo}\NormalTok{ statement}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
## statement
\end{verbatim}

So, you are just printing the word statement. Interesting ah?
